# 대지 주차장 최적 배치 설계기

지도에서 대지 경계를 그리면, 여러 회전각과 주차 형식(직각/사선/평행, 양측/편측 통로)을 자동으로
탐색하여 대지 내부에 완전히 들어가는 주차 칸을 최대한 많이 배치하는 안을 계산해 주는
정적 웹앱입니다. 서버 없이 브라우저에서 바로 동작합니다.

## 실행 방법

별도 빌드나 설치 과정이 없습니다.

- 로컬에서 열기: `parking-optimizer/index.html` 을 브라우저로 더블클릭하여 열거나,
  `npx serve parking-optimizer` 처럼 아무 정적 서버로 구동해도 됩니다.
- 인터넷 연결이 필요한 부분은 지도 배경(OpenStreetMap 타일)뿐이며, 그 외 라이브러리(Leaflet)는
  `vendor/leaflet/`에 포함되어 있어 오프라인에서도 그리기·계산·내보내기 기능이 동작합니다.

## 사용 순서

1. **대지 그리기**: "대지 그리기" 버튼을 누르고 지도를 클릭해 대지 경계 꼭짓점을 순서대로 찍은 뒤,
   더블클릭하거나 "완료" 버튼으로 폴리곤을 닫습니다.
2. **제외구역 (선택)**: 기존 건물, 조경 의무구역 등 주차 배치에서 제외할 영역을 추가로 그릴 수 있습니다.
3. **출입구 위치 (선택)**: 장애인전용 등 우선 배치구역의 위치를 잡을 때 참고합니다.
4. **설계 기준 설정**: 주차 규격(일반형/경형/확장형/직접 입력), 주차 형식(자동 탐색 또는
   직각·사선·평행 직접 지정), 통로 폭, 대지경계 이격거리(setback), 계산 정밀도를 설정합니다.
   "자동 탐색"을 선택하면 여러 형식을 모두 시도해 가장 대수가 많은 안을 고릅니다.
5. **최적 배치 계산** 버튼을 누르면 결과가 지도에 표시되고, 총 주차대수·대지면적·대당 소요면적
   등이 요약됩니다. 자동 탐색 모드에서는 형식별 대안을 클릭해 비교할 수 있습니다.
6. 결과는 **DXF**(AutoCAD 등 CAD 프로그램에서 바로 열람 가능) 또는 **GeoJSON**으로 내보낼 수 있습니다.

## 알고리즘 개요

- 대지 폴리곤을 다양한 각도로 회전시키며(대지 변의 방향 + 일정 간격 스윕), 각 각도에서
  통로(차로) + 주차열로 이루어진 "모듈 밴드"를 대지 범위에 반복 배치합니다.
- 각 주차 칸은 실제 폴리곤 경계에 완전히 포함되고(설정한 이격거리 이상 확보), 지정한 제외구역과
  겹치지 않는 경우에만 유효한 칸으로 인정합니다. 오목한 대지 형상에도 대응합니다.
- 직각(90도)뿐 아니라 60/45/30도 사선주차, 평행주차의 표준 배치 공식(칸 폭/진행방향 점유폭)을
  반영하며, 통로 양측/편측 배치, 잔여 공간에 대한 보너스 단열 배치도 함께 탐색합니다.
- 여러 조합 중 총 주차대수가 가장 많은 안을 최종안으로 채택하고, 나머지 상위 조합은 대안으로 제시합니다.

## 참고 수치 (js/standards.js)

주차 칸 규격과 차로 최소 폭은 국내 주차장법 시행규칙 별표1 등을 참고한 일반적인 수치입니다.
**실제 인허가·시공 설계에는 반드시 해당 지자체 조례 및 관련 법규(소방, 장애인 편의시설 등)를
재확인해야 합니다.** 장애인전용 등 우선 배치구역 기능은 참고용 간이 배치이며, 정식 설계 시
별도 검토가 필요합니다.

## 폴더 구조

```
parking-optimizer/
  index.html          진입 페이지
  css/style.css
  js/
    geometry.js        평면좌표 변환, 점-폴리곤 포함/겹침 판정 등 기하 유틸
    standards.js        주차 규격/차로 폭 참고 상수
    optimizer.js        핵심 최적화 엔진
    exporters.js        DXF / GeoJSON 내보내기
    mapview.js           Leaflet 지도 드로잉 및 결과 렌더링
    app.js               UI 이벤트 바인딩
  vendor/leaflet/       오프라인 사용을 위해 포함한 Leaflet 라이브러리
```

이 도구는 리포지토리 루트의 AutoCAD 플러그인(`Commands.cs`)과는 독립적으로 동작하는 별도의
웹앱입니다. DXF 내보내기 기능을 통해 계산 결과를 AutoCAD로 가져와 이어서 작업할 수 있습니다.
